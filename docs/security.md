# 安全说明

## 本地加密与会话

当前开发分支使用 AES-256-GCM 保存密钥记录，PBKDF2-SHA256 100,000 次迭代派生加密密钥，每次加密生成独立 16 字节盐和 12 字节 IV。主密码验证信息使用独立盐及 PBKDF2-SHA256 600,000 次迭代。旧版单次 SHA256 验证信息在成功登录后升级；旧版明文密钥、待导入数据和明文快照在验证成功后加密迁移。迁移全部加密成功后才删除旧明文。

持久存储不保留主密码原文。管理解锁期间主密码保存在 `chrome.storage.session`；管理会话有效期为 15 分钟，活动可延长，浏览器关闭后失效。编辑、删除、导出、恢复和更改设置仍需要有效管理会话。管理锁定后扩展页面清除原始密钥和编辑状态。

日常验证码免密默认开启。主密码成功解锁或写入密钥时，建立用独立随机设备密钥加密的 OTP 副本，设备密钥仅保存在当前浏览器的可信扩展存储中，不保存主密码。后台可在管理锁定或浏览器重启后读取副本并生成验证码；弹窗和内容脚本只接收账户元数据及验证码。主库版本变化时必须同步更新副本，版本不一致时拒绝使用。旧数据没有设备副本时需用主密码解锁一次。设置中关闭免密后移除设备能力，验证码恢复为解锁后使用。

设备密钥和副本均位于同一浏览器配置中，因此开启免密意味着能使用此浏览器的人可以生成验证码，复制整个浏览器存储的人也可能恢复 OTP 密钥。主密码在此模式下保护管理入口与主密码加密的可移植备份，不能再被视为本设备 OTP 的离线解密屏障。设备密钥和设备副本不进入导出、快照或云端备份。

本地及会话存储限制为 `TRUSTED_CONTEXTS`。内容脚本通过后台消息取得当前站点匹配的元数据，生成验证码时再次校验页面站点。写入、恢复、改密码和云端管理消息仅允许扩展页面调用。扩展页面的保存包含版本校验，避免旧页面覆盖已经更新的记录。

本地快照始终加密。导出和目录备份可由用户关闭加密；此时生成的文件包含明文密钥。明文站点索引、设置、删除墓碑和计数器指纹属于元数据，不能理解为整个浏览器存储都已加密。

## OTP 与计数器

支持 TOTP/HOTP、SHA1/SHA256/SHA512 和 6/8 位验证码。二维码导入保留算法、周期和 HOTP 计数器。预览 HOTP 不递增；复制或填充时后台串行生成并先持久化下一计数器。复制或填充失败可能跳过一个计数，不会重用该次计数。

HOTP 最大已用计数保存在本地指纹索引中，并随备份同步；恢复、编辑和合并不会回退同一密钥已知的最大计数。免密填充同样先持久化计数器及设备副本，再返回验证码；管理解锁后主库读取会应用最新计数，锁定期间的自动密文备份携带最新计数器元数据。主库迁移与验证码消费在后台串行处理。旧备份或重置后的全新设备可能缺少较新计数信息。多台离线设备同时使用同一 HOTP 密钥仍可能产生重复验证码，建议 HOTP 使用单一设备；TOTP 无此计数器协调问题。

批量清空默认仅清理本机并停用云同步；同时清理云端需单独选择、检查范围和输入确认文字。后台确认令牌绑定当前数据及云端配置，并校验并发版本。单个云端历史删除仅允许本前缀内的历史对象，保护当前同步版本与索引。实际云端删除只发生在用户选择并确认后或已配置的保留策略清理中。

## 云端与恢复

云端同步默认关闭，只向用户启用并授权的 S3/OSS Endpoint 上传密文。云端密码默认复用配置时的主密码，也可使用独立密码；云端密码与 S3 凭据由主密码加密保存。修改主密码只重加密这组凭据，保留原云端密码以继续解密历史版本。标准 S3 使用拉取时的 ETag 条件写入；OSS 使用带位置校验的追加索引。S3 412 / OSS 409 冲突保留不可变历史对象，暂停自动同步，用户比较后可保留本地、保留云端或合并。再次并发更新仍会拒绝写入。

替换回滚前保存当前加密快照，对被移除记录生成删除墓碑，对主动恢复的记录更新版本时间。HOTP 已知最大计数仍被保留。修改主密码时重新加密当前记录、凭据及能由当前密码解密的快照；历史独立密码快照可在恢复时输入原密码。

## 使用与验证边界

使用足够强且独立的密码，另行保存站点恢复码与外部加密备份。清除浏览器数据或卸载会丢失本地记录、快照和计数历史。解锁期间受感染的操作系统、浏览器或扩展代码可以接触内存中的敏感数据，存储加密不能覆盖这一风险。

自动化测试覆盖标准验证码向量、过期会话、存储迁移、恢复与模拟 S3 冲突。浏览器实机行为、真实 S3 权限/兼容性与双设备使用需要单独验收。以上实现与测试不能替代独立安全审计。
