# 功能特性

## 密钥管理

### 添加密钥

支持多种方式添加 TOTP 密钥：

1. **手动输入** - 点击扩展图标右上角 **+** 按钮，输入密钥信息
2. **右键菜单** - 在网页中的二维码图片上右键，选择「识别并添加」
3. **导入备份** - 从备份文件批量导入密钥

**密钥信息：**

| 字段 | 说明 | 必填 |
|------|------|------|
| 密钥 | Base32 编码的 TOTP 密钥 | ✅ |
| 站点 | 目标网站域名 | ✅ |
| 名称 | 自定义显示名称 | ❌ |
| 位数 | 验证码长度（6/8位） | 默认 6 位 |

### 编辑与删除

- 将鼠标悬停在密钥卡片上，显示操作按钮
- 点击编辑图标修改密钥信息
- 点击删除图标移除密钥（需确认）

### 搜索过滤

在管理页面或弹窗中输入关键词，实时过滤匹配的密钥。

## 验证码生成

### TOTP 标准

- 完全兼容 [RFC 6238](https://tools.ietf.org/html/rfc6238) 标准
- 支持 6 位和 8 位验证码
- 默认 30 秒，可配置 1～3600 秒 TOTP 周期
- SHA1 / SHA256 / SHA512 算法；支持 HOTP 及显式计数器

### 实时倒计时

- 验证码卡片显示剩余有效时间（圆环进度）
- 倒计时结束前 5 秒显示警告色
- 自动刷新验证码

### 一键复制

点击验证码卡片即可复制到剪贴板，复制成功后显示提示。

## 智能匹配

### 自动识别站点

扩展自动识别当前访问的网站：

1. 解析当前页面 URL，提取域名
2. 与已保存的密钥站点进行匹配
3. 扩展图标显示匹配数量（Badge）

### 匹配规则

- 支持主域名匹配（如 `github.com` 匹配 `gist.github.com`）
- 支持子域名匹配
- 不区分大小写

## 主密码保护

### 功能说明

主密码用于保护敏感操作，设置后：

- 打开管理页面需要验证主密码
- 导出备份需要验证主密码
- 管理会话超时后，管理、导出和更改设置需要重新验证
- 日常匹配、查看、复制和填充验证码默认免密，浏览器重启后仍可使用
- 旧数据首次升级需成功解锁一次；设置中可关闭日常免密

### 安全机制

- 主密码不持久保存到本地磁盘，验证信息使用 PBKDF2-SHA256 600,000 次迭代
- 解锁密码暂存于仅可信扩展上下文可访问的 chrome.storage.session，浏览器关闭后失效
- 会话超时时间：15 分钟

### 设置主密码

1. 打开管理页面 → 设置 → 主密码
2. 输入并确认主密码
3. 建议使用强密码（8 位以上，包含字母数字符号）

## 自动备份

### 备份频率

支持多种自动备份频率：

| 频率 | 说明 | 适用场景 |
|------|------|---------|
| 每 5 分钟 | 测试/开发环境 | 开发调试 |
| 每天 | 默认推荐 | 日常使用 |
| 每周 | 较低使用频率 | 数据变化较少 |
| 每月 | 极低使用频率 | 静态密钥 |

### 备份快速路径

自动备份支持无需解锁的快速路径：

- **主密码模式**：直接复用已加密的密钥数据备份
- **自定义密码模式**：使用独立备份密码的加密副本备份
- 会话过期后仍可正常执行自动备份
- 无需重新输入主密码

## 数据存储

### 存储位置

所有数据存储在 Chrome Storage API 中：

| 数据 | 存储方式 | 说明 |
|------|---------|------|
| 密钥主库 | 加密存储 | 主密码加密，用于管理和备份 |
| 日常验证码副本 | 设备密钥加密 | 设备密钥在可信扩展本地存储，支持免密；不进入备份 |
| 加密密钥副本 | 加密存储 | 用于自动备份快速路径 |
| 站点列表 | 明文 | 用于 Badge 显示 |
| 设置 | 明文 | 用户偏好设置 |
| 备份快照 | 始终加密 | 本地历史版本 |

### 数据安全

- 默认在浏览器本地加密保存记录；云端同步需主动启用
- 启用后仅向用户配置的 S3/OSS 上传整体密文
- 不使用 chrome.storage.sync
- 本地快照始终加密；导出和目录文件可由用户选择明文

## 管理页面

点击扩展图标右上角的「管理」按钮，进入完整管理页面。

### 功能模块

| 模块 | 功能 |
|------|------|
| 密钥列表 | 查看、搜索、编辑、删除所有密钥 |
| 导入导出 | 备份恢复操作 |
| 设置 | 主密码、自动备份、备份加密等配置 |
| 关于 | 版本信息、项目链接、隐私政策 |

### 退出登录

管理页面侧边栏底部提供「退出登录」功能：

- 清除当前会话
- 下次管理操作需要重新验证主密码，日常验证码免密继续生效
- 不影响本地存储的加密数据

详见 [备份与恢复](backup.md) 文档。
