# 备份与恢复

## 备份类型

| 类型 | 存储位置 | 加密与保留 |
|---|---|---|
| 本地快照 | 当前浏览器 | 始终加密，最近 5 份 |
| 文件导出 | 用户下载目录 | 根据设置选择明文或加密 |
| 目录备份 | 用户单独授权的目录 | 根据备份设置；授权失效时提示重新授权 |
| 云端历史 | 用户的 S3/OSS | 整体密文，默认最多 30 份、最长 90 天 |

添加、编辑和删除后创建本地快照。定时备份需在设置中开启，可选择每 5 分钟、每天、每周或每月。已存在对应加密副本时，后台可在锁定状态下复制密文到快照或目录；其他情况需要解锁。目录未授权、权限失效或云端请求失败会显示错误，不能将快照成功视为全部目标成功。

本地快照不会因文件导出选择明文而取消加密。明文导出/目录文件包含完整密钥，请妥善保存。主密码、独立备份密码和云端密码可能不同。

## 本地快照

打开管理页面 → 备份恢复 → 本地快照恢复，列表自动读取并随快照变化更新，也可手动刷新。选定方式后点击恢复，在确认窗口核对快照时间、密钥数量和恢复影响；可取消或按 Esc 退出，恢复期间禁用重复操作。失败原因保留在窗口中，可重试：

- **合并导入**：同 ID 使用所选版本内容，其余当前记录保留。
- **替换回滚**：以所选版本作为当前记录集，删除版本中不存在的当前记录；空版本也可以恢复。

替换前会提示影响；后台在修改前保存当前加密快照。恢复中的记录更新版本时间，移除的记录生成删除墓碑，防止旧设备同步时将它们重新带回。主动从旧版本恢复的已删除记录允许复活。

HOTP 恢复保留本地和备份中已知的最大计数器，不会将已使用计数回退。恢复到全新设备前应取得最新版本；同一 HOTP 密钥不适合多台设备离线同时使用。

## 文件导入

选择 JSON 文件后校验备份格式和版本。加密备份先尝试当前主密码或已保存备份密码，也可手动输入原密码。重复记录可跳过、覆盖或全部保留。全部保留会生成独立 ID 并保留原站点，副本携带 `duplicateOf`，参与同步的其他设备也应升级。

文件导入按站点与密钥识别重复项；本地快照和云端版本的合并/回滚按记录 ID 操作，两者语义不同。失败时不会把无法解密的数据当作空备份。

## 云端恢复与冲突

在设置页主动启用自己的 S3/OSS 配置。云端同步保留独立开关，无需同时开启“自动备份”，但与本地定时备份共用调度入口；开启云同步时共享任务每 5 分钟运行，本地备份只在自身设定时间到达时执行。解锁和快照变化也会触发同步。只有解锁会话可以解密和上传。保存云端配置时会开启本地快照。网络失败按 5、15、60、180 分钟退避重试。

阿里云 OSS 使用 S3 兼容地址 `https://s3.oss-地域.aliyuncs.com` 和 Bucket 子域名；普通 OSS 地址会自动转换，Path-style 会自动关闭。写入与索引追加使用原生 OSS 地址。保存、测试连接或立即同步会申请两种 Bucket 主机的访问权限。连接测试读取版本列表，空桶算连接成功，首次同步会创建历史密文与最新版本（S3 的 latest.opb / OSS 的 latest.idx）；Bucket 不存在或无权限会报错。测试连接不写入对象，不代表已验证写入或条件写入权限。

首次配置云端备份默认使用当前解锁的主密码，无需再次输入；也可选择独立密码。已保存配置默认沿用原云端密码，修改本地主密码不会更改它。其他设备连接同一备份时应使用创建该备份时的云端密码。已有云端位置不允许直接改用另一密码；需更换对象前缀建立新备份，旧版本仍用原密码恢复。

已有配置时，进入设置页会自动读取云端历史，默认收起配置表单；历史每页显示 5 个版本，可翻页或刷新。读取失败会显示原因并提供重试。密码方式按实际已保存值回显，使用当前主密码的配置保存及重新进入后仍显示主密码；主密码更换后显示沿用原主密码，以保持旧版本可解密。保存配置后等待一次同步完成；同步失败时明确区分配置已保存与同步未完成。

设置页的“版本恢复方式”同时作用于最新版本与历史版本恢复，支持合并导入或替换回滚。历史独立密码版本解密失败时可输入原密码。

S3 412 或 OSS 409 追加位置冲突时自动同步暂停。点击“比较本地与云端”查看两端数量、不同记录的站点/时间/计数器以及密钥是否变化，然后选择保留本地、保留云端或自动合并。比较结果不会展示密钥原文。后台验证本地数据和配置仍是比较时版本，并以比较时的 S3 ETag 或 OSS 索引位置提交云端；数据变化后需重新比较。

历史保留清理只处理当前前缀的历史对象，不删除最新版本或索引；OSS 只清理已提交旧对象，保留未提交上传，冲突残留对象可能超过数量限制。OSS 索引当前上限为 8 MiB，达到上限时需更换前缀，不应手动覆盖或删除索引。缺少列表或删除权限会单独显示清理失败。禁用同步、清空浏览器数据或卸载扩展不会删除外部文件和云端对象。

## 显式清理

“清空密钥”默认选择仅清理本机：先检查范围并输入 `DELETE`，清空本机密钥和快照，停用云同步，不生成同步删除记录、不访问云端备份。再次启用同步会重新读取云端记录。

选择“同时清理云端”后，检查当前 Bucket/前缀、两端密钥数量和云端历史数量，输入 `DELETE CLOUD`。后台绑定此次确认的数据和配置，先用观察到的同步版本提交空的最新记录及删除墓碑，再清空本机并删除本次确认的历史对象。其他设备会同步删除；保留空的当前同步版本与 OSS 索引，本机仅保留新的空快照作为同步基线。并发提交失败时保留本机和历史，部分历史删除失败时明确提示；不删除确认后由其他设备新建的版本。

云端列表提供单个历史快照删除，需检查所选版本并输入 `DELETE`；当前同步版本受保护。清理或删除过程中配置、会话变化会停止后续删除。停用自动云同步后仍可主动查看、恢复和删除历史，无需先恢复自动同步。“重置数据”仅重置本机数据及配置，不删除云端对象。

## 密码与兼容性

当前格式版本为 1；格式 0 数组和已识别的旧文件支持导入。有应用版本的备份支持同主版本、同次版本或低一个次版本；较新版本或跨度过大将拒绝导入。修改主密码会重新加密当前记录和可解密快照，历史独立密码快照仍需原密码。密码丢失无法解密对应备份。

当前自动化验证不包含实际浏览器目录授权、对象存储服务权限或双设备验收。
